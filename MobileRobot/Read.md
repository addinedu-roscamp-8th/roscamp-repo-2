Pinky (Empty by Design)

This directory is intentionally left empty.

All Pinky low-level control and bringup
(e.g. hardware interface, ros2_control, motion drivers)
are executed directly on the Pinky onboard controller.

High-level task and scenario logic
(e.g. pick-and-place execution, task sequencing, factory flows)
is implemented outside this directory
under the workspace-level task coordinator or scenario manager.
